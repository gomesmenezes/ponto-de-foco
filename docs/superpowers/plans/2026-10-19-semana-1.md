# Semana 1 — Implementation Plan

> **For agentic workers:** executar nesta sessão com superpowers:executing-plans; acompanhar os itens abaixo.

**Goal:** entregar o protótipo navegável e o setup inicial do Ponto de Foco.
**Architecture:** monorepositório npm com frontend responsivo e API isolada. Dados demonstrativos em memória; modelo SQL sem integração.
**Tech Stack:** React, TypeScript, Vite, Leaflet, Node.js, Fastify; PostgreSQL/PostGIS no modelo e Expo/SQLite planejados.
**Spec:** `docs/superpowers/specs/2026-10-19-semana-1-design.md`.

## Global Constraints

- Somente semana 1, em português, dados fictícios e simulações identificadas.
- Não implementar persistência, autenticação real, sincronização real ou publicação.
- Não atribuir trabalho a integrantes inexistentes.

## Review Focus

- Rotas diretas sem sessão ou sem preparação devem retornar ao início correto.
- Cancelar uma visita não deve gerar registro parcial.
- Rede ausente ou rejeição de sincronização deve preservar a fila demonstrativa.
- Celular de 390 px não deve apresentar conteúdo cortado ou navegação inacessível.
- Atualizar a página reinicia dados; nenhum rótulo deve prometer persistência real.
